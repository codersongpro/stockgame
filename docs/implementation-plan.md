# 샌드박스 내장형 학습 캠페인 구현 계획

## Phase 1

- 레벨을 6단계로 확장한다.
- 기존 저장 레벨 `elementary`, `university`는 각각 `elementary_high`, `adult`로 변환한다.
- 저장 데이터는 로드 시 검증하고, 손상된 저장값은 앱을 중단시키지 않는다.
- 기존 100분기 자유 경영 흐름은 유지한다.

## Phase 2

- 학습 캠페인은 별도 퀴즈 화면이 아니라 샌드박스 게임 안의 안내 레이어로 제공한다.
- 새 게임 설정에서 `학습 안내 켜기`를 선택하면 `GameState.campaign`에 진행 상태를 저장한다.
- 캠페인 목표는 실제 경영 행동과 분기 결과로 판정한다.
- 실패는 게임 오버가 아니라 같은 목표 재도전으로 처리한다.
- `/learn` 직접 접근은 샌드박스 설정 화면으로 안내한다.

## 품질 기준

- 초등 1~2학년, 3~4학년, 5~6학년 캠페인 문구는 서로 다른 개념 범위와 단어 수준을 유지한다.
- 초등 저학년 목표에는 고급 금융 용어와 자유 숫자 입력 중심 과제를 노출하지 않는다.
- 캠페인 판정은 외부 API 없이 기존 게임 상태와 규칙 기반 함수로만 처리한다.
