# 유니콘시티 현재 상태 분석

## 기준

- 기준 저장소: `codersongpro/stockgame`
- 기준 브랜치와 비교 브랜치는 서로 갈라진 상태다.
- 비교 브랜치는 기준보다 4개 커밋 앞서고 12개 커밋 뒤처져 있어 통째 병합하지 않는다.

## 현재 구조

- 앱은 Next.js App Router, React, TypeScript, Tailwind CSS, Zustand, Vitest 기반이다.
- 핵심 시뮬레이션은 `lib/engine` 아래 순수 TypeScript 모듈로 분리되어 있다.
- 기존 100분기 자유 경영 흐름은 `/setup`과 `/play`를 통해 동작한다.
- 저장은 브라우저 `localStorage`의 `uc-save-single` 키를 사용한다.

## 선별 검토 대상

- 비교 브랜치의 안내 화면, 숫자 입력, 의사결정 이벤트 구조는 학습 캠페인과 궁합이 좋다.
- 다만 기준 브랜치와 차이가 커서 이번 작업에는 직접 병합하지 않고, 추후 필요한 부분만 작은 단위로 이식한다.

## 위험

- 저장 데이터는 사용자가 오래전에 만든 4단계 레벨 값을 포함할 수 있다.
- 레벨 타입 변경은 홈, 설정, 스토리, 테스트에 함께 영향을 준다.
- 초등 저학년 캠페인은 고급 금융 용어와 자유 숫자 입력을 노출하지 않아야 한다.
